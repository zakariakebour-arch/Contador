# Contador
Este proyecto es un contador interactivo desarrollado con HTML, CSS y JavaScript, pensado para practicar manipulación del DOM, manejo de eventos, animaciones básicas y control de lógica mediante límites numéricos.

Incluye botones para sumar, restar, multiplicar por 2 y por 10, además de validaciones que evitan números negativos o mayores a 100.

Características

Contador dinámico y completamente funcional

Animaciones y estilos con CSS

Sistema de límites:

Máximo permitido: 100

Mínimo permitido: 0

Alertas cuando se intenta superar los límites

Diseño limpio y responsive

Código simple y fácil de entender

Tecnologías utilizadas:

HTML5

CSS3

JavaScript (ES6)
